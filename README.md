## [equirectangular2cube](https://github.com/LesFloraison/equirectangular2cube) : 将等距柱状投影转化为标准的六面体天空盒的单文件工具

### 构建方式

1. 克隆本仓库。 
2. 使用 Visual Studio 2019 打开 `equirectangular2cube.sln` 解决方案文件。
3. 切换到 x86_Debug 配置。
4. 编译项目以生成可执行文件。

或使用预编译发布版本

## 使用方式

1. 输入全景图文件路径（包括文件扩展名）。例如 C:\User\Floraison\Image\demo.hdr

2. 输入导出天空盒的路径。例如 C:\User\Floraison\Image\Skybox

3. 输入天空盒分辨率。例如 512
